# Security Policy

## Security Model

ShadowAPI inspects runtime HTTP traffic and detects vulnerabilities in API inventory management.

### Data Protection
- **Local Analysis**: ShadowAPI executes completely offline without exfiltrating or transmitting analyzed traffic over external networks.
- **Sensitive Key Detection**: ShadowAPI identifies and flags unmasked keys and tokens to notify security engineers of accidental exposure.

## Reporting a Vulnerability

If you identify a security defect in ShadowAPI:
1. Do not open a public issue.
2. Submit details to the repository maintainers through private GitHub security advisories.
